# TechinHOT

**TechinHOT** is a tech-industry news hotspot site built on the open-source [AIHOT](https://github.com/KKKKhazix/AIHOT) framework (MIT). It collects items from overseas tech sources (official blogs, media) plus the Techin industry-intelligence dataset, selects and clusters them with LLMs, ranks hot events, and publishes a daily briefing in Chinese.

See [README.md](README.md) for details (in Chinese). Framework documentation lives in `docs/`.
