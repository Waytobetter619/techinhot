# TechinHOT

**TechinHOT** is a personal news site for AI and tech geopolitics, built on the open-source [AIHOT](https://github.com/KKKKhazix/AIHOT) framework (MIT). It watches official blogs, media, key people's X accounts and policy sources (export controls, sanctions, tariffs, AI regulation, chip supply chains), selects and clusters items with LLMs, ranks hot events, and publishes a daily briefing in Chinese.

See [README.md](README.md) for details (in Chinese). Framework documentation lives in `docs/`.
